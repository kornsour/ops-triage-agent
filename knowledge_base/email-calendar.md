# Email and shared calendar setup

Common productivity requests (shared calendars, distribution lists, mailbox
delegation) are self-service.

1. To create a shared calendar: open the calendar app, choose "New shared
   calendar", name it, and add team members with the appropriate permission level.
2. For distribution lists, the team lead can self-manage membership in the admin
   portal.
3. Mailbox delegation requires the mailbox owner to grant access; IT does not do
   this on their behalf without owner consent.

No guarded action required; provide the steps and close the ticket.
