# Laptop and hardware issues

Physical hardware faults (flickering screen, failing battery, dead keyboard)
cannot be fixed remotely.

1. Capture the device asset tag and a short description of the fault.
2. Run the built-in display/battery diagnostic if the user is able.
3. Escalate to the IT field team to arrange a repair or swap. Flag business
   impact so loaner priority can be set.

No system-changing action is required from triage; the path is **escalate to IT
field team**.
