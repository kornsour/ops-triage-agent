# Archive

This folder holds historical and superseded documentation and records from
this project: old plans, notes, or state that a later decision replaced.

**Contents here are historical context only, not current truth.** They
describe what was once decided, proposed, or true at some point in the past —
not how the system is designed or built today. Do not use anything in this
folder to understand the current architecture, guide new work, or make
implementation decisions.

Contributors and coding agents: treat everything under `docs/archive/` as
background history, not as an active source. For the current state of the
project, see the top-level `README.md` and the live documents in `docs/`.
